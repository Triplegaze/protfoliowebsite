# Damilola Omojokun — Portfolio

A responsive portfolio for Damilola Omojokun, focused on AI applications and DevOps engineering. Built with HTML, CSS, and vanilla JavaScript; no build step is required.

## Preview locally

Open `index.html` in a browser or serve this folder with any static web server.

## Site features

- Responsive layout with light and dark themes
- Animated hero headline and scroll reveals
- About, core expertise, previous works, toolkit, and contact sections
- Project cards linking to their live applications

## Assets

Images used by the site are in `assets/`.
